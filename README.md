# 운동 패턴 코치

집에서 하는 가슴, 등, 어깨, 복근, 하체 루틴을 순서대로 따라가며 세트 기록을 남기고, Google 로그인과 Apps Script를 통해 Google Sheets에 기록을 동기화하는 정적 웹앱입니다. 푸쉬업바, 7kg 덤벨, 튜빙밴드, 고리형 밴드, AB슬라이드를 반영한 필수 7종목과 선택 2종목 루틴이며, 세트별 무게/밴드 강도와 컨디션까지 기록합니다. 운동 이미지를 클릭하면 시작, 움직임, 도착, 돌아오는 방향, 느낌, 자세 경고, 중단 기준을 볼 수 있습니다.

배포와 Google Sheets 연동 방법은 [SERVICE_AND_DEPLOYMENT.md](./SERVICE_AND_DEPLOYMENT.md)를 참고하세요.
